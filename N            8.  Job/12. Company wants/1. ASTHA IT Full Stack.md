## Position: Full-time

## Vacancy: 1

## Responsibilities:

1. Design and develop end-to-end full stack solutions using **.NET** (C#, ASP.NET Core, Web API) for backend services, and **React** or **Angular** for frontend applications.
2. Collaborate with cross-functional teams including designers, product owners, QA engineers, and DevOps to translate business requirements into scalable, maintainable, and performant software
3. Build modern, dynamic UIs with React that integrate seamlessly with backend APIs, delivering smooth and intuitive user experiences
4. Develop clean, modular, and secure code that follows industry best practices and coding standards across both frontend and backend layers
5. Continuously profile, tune, and optimize application performance to ensure lightning-fast response times and minimal resource consumption
6. Participate actively in code reviews, sharing knowledge and constructive feedback to uphold code quality across the stack
7. Identify architectural gaps, recommend technical enhancements, and refactor components to ensure long-term maintainability and scalability
8. Keep pace with the latest advancements in .NET, React, cloud services, and fullstack engineering to bring fresh ideas and innovation to the team

## Technical Requirements:

1. Strong hands-on experience with .NET technologies including C#, ASP.NET Core, and Web API for building robust and scalable backend services
2. Advanced proficiency in React, leveraging hooks, Context API, and Redux to build highly responsive and maintainable frontend applications
3. Proven ability to architect, build, and integrate RESTful APIs, ensuring seamless communication between frontend and backend systems
4. Solid understanding of SQL databases such as SQL Server and MySQL, and working knowledge of NoSQL databases such as MongoDB for flexible data storage solutions
5. Comfortable using Git for version control in collaborative development environments
6. Familiarity with Docker, cloud platforms like AWS or Azure, and microservices architecture is a plus
7. Exposure to CI/CD pipelines and automated deployments is an added advantage
8. Strong problem-solving mindset with the ability to write efficient algorithms, refactor code for performance, and debug complex issues across the stack
9. Excellent collaboration and communication skills with the ability to work seamlessly within tech teams and with other stakeholders

## Academic Requirements:

Not much. If you can fulfill the aforementioned skill requirements, we don’t care about the academic backgrounds. Your skills matter. Certificates and CGPA are secondary.

But if you have a degree (Bachelors or Masters) in CS / CSC / CSE / Software Engineering, it’s a plus of course.

All we need from you is a super-hungry learning habit and a geeky-techie spirit.

If you have a strong portfolio of complex applications/software/tools that you worked on, that would be terrific.

3 – 5 years.
