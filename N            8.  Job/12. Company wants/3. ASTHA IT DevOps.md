## Position: Full-time

## Vacancy: 1

## Job Responsibilities:
- Collaborate with development and operations teams to understand project requirements, solutions, and KPIs.
- Set up and manage required tools, infrastructure, and environments for development, testing, and deployment.
- Assist in defining and implementing DevOps processes for development, release, update, and support cycles.
- Build, maintain, and monitor CI/CD pipelines for efficient integration, deployment, and delivery.
- Troubleshoot and resolve deployment or system-related issues, coordinating with developers as needed.
- Automate routine processes to improve efficiency and reduce manual effort.
- Monitor system performance and adherence to DevOps processes; suggest and implement improvements.
- Apply cybersecurity measures by monitoring vulnerabilities and implementing risk mitigation strategies.
- Support containerization and orchestration using Docker and Kubernetes.
- Collaborate with the team to ensure smooth operations, effective communication, and adherence to project schedules.

## Technical Requirements:

- Hands-on experience with AWS or Azure cloud platforms and related services.
- Practical knowledge of CI/CD implementations using tools like AWS DevOps, Azure DevOps, or similar.
- Experience with infrastructure automation using Terraform or CloudFormation.
- Proficiency in Linux/Unix administration and system troubleshooting.
- Experience with containerization and orchestration using Docker and Kubernetes.
- Scripting proficiency in Python, Bash, or PowerShell for automating tasks.
- Familiarity with application monitoring tools on cloud platforms and interpreting system logs.
- Ability to independently troubleshoot, diagnose, and resolve issues in cloud-based environments.
- Knowledge of object-oriented programming, design patterns, and service-oriented architecture is a plus.
- Experience managing deployments, builds, and releases according to specifications.
- Comfortable working with ticket management and collaboration tools for project tracking.

## Academic Requirements:

Not much. If you can fulfill the aforementioned skill requirements, we don’t care about the academic backgrounds. Your skills matter. Certificates and CGPA are secondary.

But if you have a degree (Bachelors or Masters) in CS / CSC / CSE / Software Engineering, it’s a plus of course.

All we need from you is a super-hungry learning habit and a geeky-techie spirit.

If you have a strong portfolio of complex applications/software/tools that you worked on, that would be terrific.
