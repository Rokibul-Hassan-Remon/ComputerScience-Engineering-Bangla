## Position: Full-time

## Vacancy: 1

## Responsibilities:
- Design, develop, and maintain robust ETL/ELT processes using Talend Open Studio / Talend Data Integration / Talend Data Fabric
- Integrate data from multiple sources (databases, APIs, flat files, cloud services) into centralized data warehouses or data lakes
- Optimize data workflows for performance, scalability, and maintainability
- Ensure data quality, lineage, and compliance with governance policies
- Monitor and troubleshoot data pipelines and perform root cause analysis for data issues
- Collaborate with data architects, BI developers, and business teams to understand data requirements
- Implement and manage job scheduling, error handling, and performance tuning
- Participate in code reviews, testing, and documentation

## Technical Requirements:
- 3-5 years of experience as a Data Engineer, with a strong focus on Talend ETL or similar tools
- Excellent communication skills in English to collaborate effectively with cross-functional teams
- Proficiency in building data pipelines and transformation jobs using Talend Data Integration / Big Data / Cloud editions
- Solid understanding of data warehousing concepts, data modelling, and ETL best practices
- Strong experience in SQL and working with relational databases (e.g., Oracle, MySQL, SQL Server, PostgreSQL)
- Experience integrating with cloud platforms like AWS, Azure, or GCP (e.g., S3, Redshift, Big Query, Azure Data Lake)
- Familiarity with version control (e.g., Git), CI/CD processes, and job orchestration tools (e.g., Airflow, Control-M, or similar)
- Knowledge of data quality frameworks, data governance, and metadata management
- Strong analytical and problem-solving skills

## Academic Requirements:
Not much. If you can fulfill the aforementioned skill requirements, we don’t care about the academic backgrounds. Your skills matter. Certificates and CGPA are secondary.

But if you have a degree (Bachelors or Masters) in CS / CSC / CSE / Software Engineering, it’s a plus of course.

All we need from you is a super-hungry learning habit and a geeky-techie spirit.

If you have a strong portfolio of complex applications/software/tools that you worked on, that would be terrific.
