## 🔹 Topic 6: Browser HTML parse করলে Image request কী type?
Suppose you are using an HTML browser on a client machine **C** to access a static HTML webpage hosted on an HTTP server **S**.  
The page contains exactly **one static embedded image**, which also resides on **S**.  
Assuming **no web caching**, which of the following statements is correct when you load the webpage along with the embedded image?

a. C needs to send at least **two HTTP requests** to S using **two different TCP connections**.  
b. C needs to send at least **two HTTP requests** to S, but a **single TCP connection** is sufficient.  
c. A **single HTTP request** is sufficient **without using any TCP connection** from C to S.  
d. A **single HTTP request** is sufficient using a **single TCP connection** from C to S.

---

## ✅ Correct Answer

👉 **b. C needs to send at least two HTTP requests to S, but a single TCP connection is sufficient**

---

## 🧠 Explanation (Bangla)

- প্রথমে browser **HTML file** পাওয়ার জন্য **একটি HTTP request** পাঠায়।
    
- HTML parse করার সময় browser দেখে যে একটি **embedded image** আছে।
    
- সেই image আনার জন্য browser আবার **আরেকটি HTTP request** পাঠায়।
    

👉 তাই মোট **কমপক্ষে 2টি HTTP request** লাগে।


### ✔ Two Different Concepts (Most Important)

#### 🔹 HTTP Method

- Server বোঝে
    
- Example: `GET`
    

#### 🔹 Browser Resource Type

- DevTools বোঝায়
    
- Example: `image`
    

👉 Image request:
```txt
Method = GET
Type   = image

```

### 🔗 TCP Connection বিষয়টা

- HTTP runs **on top of TCP**।
    
- HTTP/1.1-এ **persistent TCP connection** ব্যবহার করা যায়।
    
- ফলে একই TCP connection দিয়েই multiple HTTP request পাঠানো সম্ভব।
    

📌 তাই:

- ❌ 2টা TCP connection দরকার নেই
    
- ❌ Single HTTP request যথেষ্ট না
    
- ❌ TCP ছাড়া HTTP সম্ভব না

## 1️⃣ Page load হলে কী হয়? (Browser-level)

ধরো তুমি browser-এ লিখলে:

`https://example.com/products`

### তখন browser যা করে:

1. Browser একটি **HTTP GET request** পাঠায়
    
2. Request-এর type হয় → **Document request**
    
3. Server (ASP.NET Core) থেকে response আসে:
    
    - HTML
        
4. Browser ওই HTML **parse করে**
    
5. HTML-এর ভেতরে যেগুলো আছে:
    
    - CSS
        
    - JS
        
    - Image
        

👉 এগুলোর জন্য browser **আলাদা আলাদা HTTP GET request** পাঠায়

📌 **এগুলো সব normal HTTP request**, AJAX না।

## 🔹 Topic 7: Image request AJAX কেন নয়?

### ✔ Image Request

- Browser auto-send করে
    
- HTML parse করার সময়
    
- JavaScript লাগে না
    

### ✔ AJAX Request

- JS থেকে manually call
    
- `fetch` / `xhr`
    

📌 Image request ≠ AJAX request

## 5️⃣ Network tab-এ পার্থক্য কীভাবে বুঝবে? (Real trick)

Chrome DevTools → **Network tab**

### Page load request:

- Type: **document**
    
- Initiator: **other**
    
- Method: **GET**
    

### AJAX request:

- Type: **fetch / xhr**
    
- Initiator: **script**
    

📌 এইটা দেখলেই 100% clear হয়ে যাবে

## 🔹 Topic 8: Image request Controller-এ debug ধরা পড়ে না কেন?

### ✔ ASP.NET Core
### Normal Page Load

```cs
public IActionResult Index()
{    
	return View(); 
}
```

> **Controller-এ debug শুধু তখনই ধরা পড়ে, যখন request টা ASP.NET Core application পর্যন্ত আসে।**

## 🧠 Final Golden Rules (Interview Gold)

1. **HTTP is stateless, TCP is stateful**
    
2. **Method ≠ Resource type**
    
3. **Image request = GET + image**
    
4. **Static files never hit Controller**
    
5. **One TCP connection can carry many stateless HTTP requests**
    
6. **ping = report, not load**
