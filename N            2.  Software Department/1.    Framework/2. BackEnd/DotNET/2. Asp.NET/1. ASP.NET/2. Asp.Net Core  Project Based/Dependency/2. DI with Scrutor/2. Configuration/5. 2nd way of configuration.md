## 2️⃣ **Custom Attribute দিয়ে Lifetime নির্ধারণ (Advanced)**

তুমি চাইলে **attribute** দিয়ে class-specific lifetime দিতে পারো:
```cs
[ScopedService]
public class UserService : IUserService {}

[TransientService]
public class NotificationService : INotificationService {}

[SingletonService]
public class LoggerService : ILoggerService {}

```

```cs
builder.Services.Scan(scan => scan
    .FromAssemblyOf<UserService>()
    .AddClasses(classes => classes.WithAttribute<ScopedService>())
    .AsImplementedInterfaces()
    .WithScopedLifetime()
);

builder.Services.Scan(scan => scan
    .FromAssemblyOf<NotificationService>()
    .AddClasses(classes => classes.WithAttribute<TransientService>())
    .AsImplementedInterfaces()
    .WithTransientLifetime()
);

builder.Services.Scan(scan => scan
    .FromAssemblyOf<LoggerService>()
    .AddClasses(classes => classes.WithAttribute<SingletonService>())
    .AsImplementedInterfaces()
    .WithSingletonLifetime()
);

```
