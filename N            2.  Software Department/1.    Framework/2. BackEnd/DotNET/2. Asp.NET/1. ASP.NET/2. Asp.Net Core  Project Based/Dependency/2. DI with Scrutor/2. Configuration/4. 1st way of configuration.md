
## 1️⃣ **Scrutor Lifetime Methods**

Scrutor মূলত **IServiceCollection** এর built-in DI lifetimes ব্যবহার করে।

- `.WithScopedLifetime()` → `AddScoped()`
    
- `.WithTransientLifetime()` → `AddTransient()`
    
- `.WithSingletonLifetime()` → `AddSingleton()`
    

Scrutor internally শুধু assembly scan করে class/interface বের করে, তারপর **DI container-কে বলে কোন lifetime এ register করতে হবে**।

Scrutor এ সব service এক সাথে একই lifetime নিতে পারে, কিন্তু তুমি চাইলে **class-specific lifetime** ও দিতে পারো **filter বা convention ব্যবহার করে**।

## 1️⃣ **Namespace/Folder অনুযায়ী Lifetime আলাদা করা**

ধরা যাক:
```cs
MyApp.Services
 ├─ ScopedServices
 │   ├─ UserService : IUserService
 │   └─ OrderService : IOrderService
 ├─ TransientServices
 │   └─ NotificationService : INotificationService
 └─ SingletonServices
     └─ LoggerService : ILoggerService

```

### Step 1: Scoped Services
```cs
builder.Services.Scan(scan => scan
    .FromAssemblyOf<IUserService>()
    .AddClasses(classes => classes.InNamespace("MyApp.Services.ScopedServices"))
    .AsImplementedInterfaces()
    .WithScopedLifetime()
);

```

---

### **Step 2: Transient Services**
```cs
builder.Services.Scan(scan => scan
    .FromAssemblyOf<NotificationService>()
    .AddClasses(classes => classes.InNamespace("MyApp.Services.TransientServices"))
    .AsImplementedInterfaces()
    .WithTransientLifetime()
);

```
