## 1️⃣ **Basic Concept**

Scrutor মূলত কাজ করে **assembly scanning + reflection + conventions** এর মাধ্যমে।

- **Assembly scanning** → .NET assembly (DLL/EXE) থেকে সব class/interface খুঁজে বের করে।
    
- **Reflection** → class গুলোর metadata দেখে কোন interface implement করছে বা কোন namespace/attribute আছে।
    
- **Registration** → সব matched class কে **DI container** এ register করে দেওয়া হয়, lifetime সহ।

## 2️⃣ **Typical Scrutor Workflow**

ধরা যাক আমাদের কিছু service আছে:
```cs
namespace MyApp.Services
{
    public interface IUserService { void DoWork(); }
    public class UserService : IUserService { public void DoWork() {} }

    public interface IOrderService { void Process(); }
    public class OrderService : IOrderService { public void Process() {} }
}

```

### **With Scrutor**
```cs
builder.Services.Scan(scan => scan
    .FromAssemblyOf<IUserService>()   // assembly choose করা
    .AddClasses()                      // সব class select করা
    .AsImplementedInterfaces()         // যেই interface implement করছে, তাই register
    .WithScopedLifetime()              // lifetime
);

```

- Scrutor:
    
    1. `FromAssemblyOf<IUserService>()` → এই assembly scan করবে
        
    2. `AddClasses()` → সব class খুঁজবে
        
    3. `AsImplementedInterfaces()` → প্রতিটা class কে তার interface হিসেবে register করবে
        
    4. `WithScopedLifetime()` → lifetime সেট করবে
        

✅ এক লাইনে অনেক service register হয়ে যাবে
