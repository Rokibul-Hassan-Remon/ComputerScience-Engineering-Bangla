**`IDisposable` আর `using`** actually কী কাজ করে,  
কেন দরকার হয়,  
আর Garbage Collector (GC)-এর সঙ্গে এদের সম্পর্ক কী।

---

## 🧠 আগে একটু Concept Clear করা যাক

GC কেবলমাত্র **managed memory** clean করে।  
মানে — যেগুলো CLR (Common Language Runtime) নিজে allocate করেছে (heap-এ রাখা object)।

কিন্তু কিছু resource আছে যেগুলো CLR জানে না — যেমন:

- File handle
    
- Database connection
    
- Network socket
    
- Graphics object (bitmap, stream ইত্যাদি)
    

👉 এইসব resource-কে বলে **unmanaged resources**।

---

## 🚫 GC কেন এদের clean করতে পারে না?

কারণ GC শুধু .NET heap এ থাকা object track করে।  
Unmanaged resource (যেমন file handle বা OS resource) heap-এর বাইরে থাকে।

তাই GC জানে না, কখন এগুলো close বা release করতে হবে।  
এখানেই আসে `IDisposable` এবং `using` keyword।

---

## ⚙️ `IDisposable` Interface — এর কাজ কী?

এটা একটা interface, যেখানে একটাই method আছে:
```cs
public interface IDisposable
{
    void Dispose();
}

```
👉 এই `Dispose()` method developer define করে দেয়, যাতে unmanaged resource manually clean করা যায়।

---

### 🧩 উদাহরণ:

ধরো, তুমি একটা file খুলেছো:
```cs
FileStream fs = new FileStream("data.txt", FileMode.Open);

```
এখন এই file handle (যেটা OS resource) CLR-এর managed heap-এর বাইরে আছে।  
তাই GC এটা release করতে পারবে না, unless তুমি নিজে বলো।

তুমি এটা manually clean করতে পারো:
```cs
fs.Dispose();  // File handle close হবে

```

## 🪄 `using` Keyword — Shortcut for Dispose()

যদি প্রতিবার manually `Dispose()` call করতে হয়, সেটা ঝামেলার।  
তাই C# দিয়েছে একটা shorthand — **`using` block**।
```cs
using (FileStream fs = new FileStream("data.txt", FileMode.Open))
{
    // কাজ করো file দিয়ে
}   // এখানে ব্লক শেষ হলে fs.Dispose() automatically call হবে

```

এর মানে:

- `using` automatically ensures যে resource release হবে even if exception occurs.
    
- তাই এটাকে বলে **deterministic cleanup** (মানে, ঠিক কবে resource clean হবে সেটা তুমি জানো)।
    

---

## 🧩 Simplified Diagram:
```cs
+-------------------------------+
| Managed Heap (GC cleans auto) |
+-------------------------------+
| Unmanaged Resource (GC can't) |
         ↓
   Implement IDisposable
         ↓
     Call Dispose()
         ↓
  or Use 'using' block

```
💡 Real Example (Database Connection):
```cs
using (SqlConnection conn = new SqlConnection(connString))
{
    conn.Open();
    // Query execute করো
}  // এখানে conn.Dispose() call হয়ে connection close হবে

```
