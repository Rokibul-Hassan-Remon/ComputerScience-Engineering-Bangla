## 🧠 Overview: What is the “Managed Heap”?

যখন তুমি `.NET` এ `new` keyword ব্যবহার করে object তৈরি করো (যেমন `new Student()`), তখন সেই object **managed heap** নামের একটা memory region এ store হয়।  
এই heap কে বলে **managed**, কারণ এটা **.NET Garbage Collector (GC)** দ্বারা স্বয়ংক্রিয়ভাবে manage হয়।  
মানে developer কে `free()` বা `delete` করার দরকার হয় না — GC automatically unused object গুলো পরিষ্কার করে ফেলে।

---

## 🔢 .NET Heap Generations (0️⃣, 1️⃣, 2️⃣)

Microsoft-এর অফিসিয়াল ডক বলছে:

> “To optimise the performance of the garbage collector, the managed heap is divided into three generations: 0, 1, and 2.”  
> — [Microsoft Docs (Automatic Memory Management)](https://learn.microsoft.com/en-us/dotnet/standard/automatic-memory-management?utm_source=chatgpt.com)

---

### 🧩 Generation 0 (Gen 0)

- এখানে **নতুন তৈরি হওয়া object** গুলো store হয়।
    
- সবচেয়ে ছোট generation, এবং সবচেয়ে ঘন ঘন collect হয়।
    
- GC যখন Gen 0 full হয়, তখন GC চলে (collection হয়)।
    
- অনেক সময় একে **short-lived object area** বলা হয় (যেমন temporary variables, short function objects ইত্যাদি)।
    

**Example:**
```cs
void Demo() {
    var temp = new StringBuilder(); // Gen 0 তে যায়
}

```

`temp` function শেষ হওয়ার পর আর reference না থাকলে, GC সহজেই ওকে collect করে।

---

### 🧩 Generation 1 (Gen 1)

- এটা একটা **buffer zone** এর মতো।
    
- Gen 0 থেকে যেসব object একবারের garbage collection এ বেঁচে যায় (মানে এখনো referenced আছে), তারা “promote” হয়ে Gen 1 এ যায়।
    
- এটা medium-lived object এর জন্য ব্যবহৃত হয়।
    

---

### 🧩 Generation 2 (Gen 2)

- এটা হলো **long-lived object region**।
    
- Gen 1 থেকেও যেগুলো একাধিক GC cycle বেঁচে যায়, তারা Gen 2 তে promote হয়।
    
- উদাহরণ: global/static objects, cache data, বা application lifetime অবধি থাকা objects।
    

---

## 🚀 Why Generations?

Microsoft GC team বলছে:

> “Generations improve GC performance by not scanning the whole heap every time.”  
> — [Microsoft Docs (GC Fundamentals)](https://learn.microsoft.com/en-us/dotnet/standard/garbage-collection/fundamentals?utm_source=chatgpt.com)

এর মানে —

- GC প্রতিবার পুরো heap scan করে না।
    
- বরং Gen 0 তে focus করে, কারণ বেশিরভাগ garbage ওখানেই তৈরি হয়।
    
- এতে GC আরও efficient হয় (less CPU time, faster allocation)।
    

---

## ⚙️ Bonus: Large Object Heap (LOH)

Microsoft docs অনুযায়ী:

> “Objects that are 85,000 bytes or larger are allocated in the Large Object Heap (LOH), which is collected only during a full, generation 2 collection.”

মানে —

- অনেক বড় object (যেমন বড় array বা string) আলাদা জায়গায় store হয়।
    
- LOH-ও technically “generation 2” এর অংশ হিসেবে ধরা হয়, কিন্তু কম ঘন ঘন collect হয়।
