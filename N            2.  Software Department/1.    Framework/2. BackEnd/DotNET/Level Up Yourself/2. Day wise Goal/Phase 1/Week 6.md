# ✅ Day-by-Day Detailed Plan

### **Day 1 (2-3 hours)**

**Topic:** Clean Code Principles  
**Learn:**

- Meaning of Clean Code (Robert C. Martin)
    
- Naming conventions → meaningful names
    
- Method size → single responsibility
    
- Classes → cohesion
    
- Comments → only when necessary
    

**Practice:**

- Refactor Week 4 API project code for readability & maintainability
    
- Reduce method size, improve naming, remove magic numbers
    

**Resources:**

- Book: _Clean Code_ – Chapters 1–3
    
- YouTube: Nick Chapsas – Clean Code in C#
    

---

### **Day 2 (2-3 hours)**

**Topic:** SOLID Principles – Single Responsibility & Open/Closed  
**Learn:**

- SRP → one class = one responsibility
    
- OCP → extendable without modifying existing code
    
- Apply in Service + Repository layer
    

**Practice:**

- Refactor ProductService → split responsibilities
    
- Add new functionality without changing existing classes
    

---

### **Day 3 (2-3 hours)**

**Topic:** SOLID Principles – Liskov & Interface Segregation  
**Learn:**

- LSP → derived classes substitute base class without breaking
    
- ISP → small interfaces for specific clients
    

**Practice:**

- Refactor existing service to multiple interfaces
    
- Implement polymorphic behavior safely
    

---

### **Day 4 (2-3 hours)**

**Topic:** SOLID Principles – Dependency Inversion  
**Learn:**

- Depend on abstractions, not concrete classes
    
- DI container in ASP.NET Core
    
- Constructor injection vs Method injection
    

**Practice:**

- Refactor controllers + services → use DI properly
    
- Remove hard-coded dependencies
    

---

### **Day 5 (2-3 hours)**

**Topic:** Unit Testing Basics – xUnit  
**Learn:**

- Arrange – Act – Assert pattern
    
- Fact vs Theory attributes
    
- Test naming convention
    
- Setup & Teardown
    

**Practice:**

- Write unit test for ProductService
    
- Test AddProduct, GetProduct, UpdateProduct
    

**Resources:**

- YouTube: Nick Chapsas – xUnit Tutorial
    
- Docs: xUnit.net
    

---

### **Day 6 (2-3 hours)**

**Topic:** Mocking & NSubstitute  
**Learn:**

- Why mocking → isolate dependencies
    
- NSubstitute → mock repository, service
    
- Verify method calls, exceptions, return values
    

**Practice:**

- Mock ProductRepository in ProductService unit tests
    
- Verify AddProduct / GetProduct call
    
- Simulate exceptions & assert
    

**Resources:**

- YouTube: Nick Chapsas – NSubstitute
    
- Docs: NSubstitute Official
    

---

### **Day 7 (2-3 hours)**

**Mini Project:** Full API + SOLID + Unit + Integration Tests

**Requirements:**

- Product + Order API (Week 4-5)
    
- Refactor code → SOLID + Clean Code
    
- Unit Test all services with xUnit + NSubstitute
    
- Integration Test API endpoints (WebApplicationFactory or TestServer)
    
- Verify exception handling, validation, authorization
    

**Self-Test Checklist:**

- Can I apply Clean Code in real project?
    
- Can I implement all SOLID principles?
    
- Can I write unit tests with mocks?
    
- Can I write integration tests for API?
    
- Am I ready for **Phase 2: Advanced API Design + Cloud + Architecture**
