### **Summary of Key Points আমরা Cover করেছি:**

1. **Basic CRUD Endpoints (Book API)**
    
    - `POST /books` → Create new book
        
    - `GET /books/{bookId}` → Get specific book
        
    - `PATCH /books/{bookId}` → Partial update (e.g., price)
        
    - `DELETE /books/{bookId}` → Delete book
        
    - `GET /books` → Get all books
        
2. **Filtering, Sorting, Pagination**
    
    - Filter by author: `GET /books?author=Rokibul`
        
    - Pagination: `GET /books?page=2&pageSize=5`
        
    - Sort + Filter + Pagination combined:
        
```cs
        GET /books?author=Rokibul&page=2&pageSize=5&sort=price&order=desc
```
        
3. **Nested Resources**
    
    - Book reviews: `GET /books/{bookId}/reviews`
        
    - Partial update of nested resource: `PATCH /books/{bookId}/reviews/{reviewId}`
        
4. **PUT vs PATCH**
    
    - PUT → Full replace
        
    - PATCH → Partial update
        
    - Model binding behavior: missing parameters → default values
        
5. **Query Parameter vs Path Parameter**
    
    - `/books?id=1` → traditional MVC / filter
        
    - `/books/1/reviews` → proper RESTful nested resource
