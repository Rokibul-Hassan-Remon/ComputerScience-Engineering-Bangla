# ⭐ **Level 3 REST API – Full Cheat Sheet**

## **1) Basic Resource**

- Resource সবসময় plural হবে  
    `/books`, `/authors`, `/orders`, `/reviews`
    

---

# 🟦 **A. Filtering (Query Parameters)**

### ✔️ Example

```cs
GET /books?author=Rokibul&minPrice=500&maxPrice=1500
```

### ব্যবহার:

- Filtering data
    
- Typical query: search fields
    

---

# 🟦 **B. Sorting**

```cs
GET /books?sort=title&order=asc GET /books?sort=price&order=desc
```

### ব্যবহার:

- Ordered list show করার সময়
    
- sort = which field
    
- order = asc | desc
    

---

# 🟦 **C. Pagination**

```cs
GET /books?page=2&pageSize=10
```

### ব্যবহার:

- Load limited data
    
- For large DB list screens
    

---

# 🟦 **D. Include (Nested Resources Inside List)**

```cs
GET /books?include=author,reviews
```

### Use case:

- Book list + Author info একসাথে
    
- Book list + Reviews include করা
    

---

# 🟦 **E. Nested Resource (Sub Resource)**

### ✔️ Getting all reviews of a specific book

```cs
GET /books/{bookId}/reviews
```

### ✔️ Adding a new review to a book

```cs
POST /books/{bookId}/reviews
```

### ✔️ Updating a single review

```cs
PATCH /books/{bookId}/reviews/{reviewId}
```

---

# 🟦 **F. Bulk Operations**

### 1) Bulk Delete

```
DELETE /books
Body: 
{   
 "ids": [1,2,3,4] 
}
```

### 2) Bulk Update

```cs
PUT /books
Body: [
  { "id": 1, "price": 500 },
  { "id": 2, "price": 600 }
]

```

### 3) Bulk Review Update
```cs
PATCH /books/{bookId}/reviews
Body: [
  { "id": 1, "text": "Updated review" },
  { "id": 2, "text": "Better book now" }
]

```


---

# 🟦 **G. Single Resource Operations**

### ✔️ Add new book

```cs
POST /books
```

### ✔️ Get single book

```cs
GET /books/{id}
```

### ✔️ Update full book (replace)

```cs
PUT /books/{id}
```

### ✔️ Update partial fields (patch)

```cs
PATCH /books/{id}
```

### ✔️ Delete single

```cs
DELETE /books/{id}
```

---

# 🟦 **H. Advanced Filtering**

### 1) Multiple filter combinations

```cs
GET /books?author=Remon&minPrice=500&maxPrice=2000&page=1&pageSize=10
```

### 2) Full text search

```cs
GET /books?search=programming
```

---

# 🟦 **I. ASP.NET Controller Parameter Binding**

|Attribute|Meaning|
|---|---|
|**[FromQuery]**|Query string থেকে data bind|
|**[FromRoute]**|URL route থেকে bind (`{id}`)|
|**[FromBody]**|JSON body থেকে bind|
|**[FromHeader]**|Custom header থেকে bind|
|**[FromForm]**|Form-data (file upload)|
|**[FromServices]**|DI service inject|
