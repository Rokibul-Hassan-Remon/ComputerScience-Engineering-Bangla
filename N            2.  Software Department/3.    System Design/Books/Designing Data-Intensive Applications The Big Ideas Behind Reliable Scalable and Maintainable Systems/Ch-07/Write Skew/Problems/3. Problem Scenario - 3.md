## ✅ 3. **Multiplayer Game – একই পজিশনে Move করা**

### 📖 সমস্যা কী:

ধরো একটা game আছে — যেমন: Chess বা Ludo।  
দুজন player আছে — Alice ও Bob।

তারা **একই বোর্ড পজিশনে** তাদের গেম পিস (figure) move করতে চায়।

- Alice দেখে জায়গাটা ফাঁকা
    
- Bob-ও একই সময় দেখে জায়গাটা ফাঁকা
    

তারা দুজনেই ভাবে: "আমি এখানে move করতে পারি"

🔄 ফলে তারা **দুজনেই একই জায়গায় move করে দেয়** → খেলায় গোলমাল হয় ❌

### 💣 কেন এটা ঘটে?

কারণ আবারও,

- দুজন একই সময় জায়গা খালি দেখে
    
- write করার সময় কে আগে move করল সেটা বোঝার system নেই
