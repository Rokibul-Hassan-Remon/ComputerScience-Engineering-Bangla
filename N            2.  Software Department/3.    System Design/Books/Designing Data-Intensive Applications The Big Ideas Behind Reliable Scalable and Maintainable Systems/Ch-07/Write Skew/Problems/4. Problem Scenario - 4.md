## ✅ 4. **Username Claiming System**

### 📖 সমস্যা কী:

ধরো তুমি একটা নতুন অ্যাকাউন্ট খুলতে যাচ্ছো — তুমি দেখতে চাও:

> "Username ‘remon123’ কি খালি আছে?"

তুমি চেক করলে — খালি ✅

**একই সময়ে**, অন্য একজন user-ও চেক করলো — সেও দেখলো খালি ✅

🔄 দুইজনেই এখন username টি নিবন্ধন করে ফেলে → ফলাফল ❌ Conflict ❗

### 💣 কেন এটা ঘটে?

- দুজনেই “read” করল username খালি কিনা
    
- দুজনেই “write” করে দিল username claim করার চেষ্টা করে
