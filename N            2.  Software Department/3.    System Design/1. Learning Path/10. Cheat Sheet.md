1. Write + Spike → Queue  
Handle sudden write bursts without overwhelming your system.  
  
2. Latency + Global → CDN  
Serve content closer to users to reduce global latency.  
  
3. Load + Growth → Scale Out  
Add more machines horizontally as demand increases.  
  
4. Read + Bottleneck → Cache  
Speed up repeated reads and reduce database pressure.  
  
5. Requests + Spike → Throttle  
Control traffic surges to protect downstream services.  
  
6. Retry + Safety → Idempotent  
Ensure repeated operations don’t cause duplicate effects.  
  
7. Core + Failure → Redundancy  
Duplicate critical components to avoid single points of failure.  
  
8. Dataset + Growth → Sharding  
Split data across nodes for performance and scalability.  
  
9. Text + Search → Inverted Index  
Enable fast full-text search across documents.  
  
10. Upload + Large File → Chunking  
Break huge files into parts for reliable, resumable uploads.  
  
11. Durability + Failure → Replication  
Copy data across nodes to prevent loss and improve reliability.  
  
12. Broadcast + Realtime → Pub/Sub  
Push real-time events to many subscribers efficiently.  
  
13. Location + Search → Geohashing  
Index geographic data for fast proximity queries.  
  
14. Write + Conflict → Optimistic Locking  
Avoid locks by detecting conflicting writes at commit time.  
  
15. Untrusted + Execution → Container  
Isolate workloads safely in standardized environments.  
  
16. Realtime + Updates → WebSockets  
Enable live, bidirectional communication with clients.  
  
17. Traffic + Reliability → Load Balancer  
Distribute requests evenly and keep services healthy.  
  
18. Distributed + Transaction → Saga Pattern  
Coordinate multi-step workflows without distributed locks.  
  
19. Concurrency + Consistency → Row Locking  
Protect shared data from race conditions during updates.
