## 1️⃣ Traversal & Reverse Linked List

🪐 **Core Insight:**  
These problems often need a `prev` variable to:

- Remove certain nodes
    
- Reverse linked lists in-place
    

**Template for removing nodes:**
```py
dummy = ListNode()
dummy.next = head
prev = dummy
while head:
    if hashmap[head.val] > 1:
        prev.next = head.next
    else:
        prev = head
    head = head.next
return dummy.next

```


**Template for reversing a linked list:**
```py
prev = None
while head:
    next = head.next
    head.next = prev
    prev = head
    head = next
return prev

```

## 2️⃣ Fast & Slow Pointer

🪐 **Usage:**

- Find middle of the linked list:
    
    - Odd length → slow points to middle
        
    - Even length → slow points to (n/2 + 1)-th node
        
- Detect cycle:
    
    - If cycle exists, fast and slow pointers meet.
        

**Template:**

```py
fast, slow = head, head
while fast and fast.next:
    fast = fast.next.next
    slow = slow.next

```

## 1️⃣3️⃣ Tricks

✅ **Constructing Integer from Linked List:**

When constructing an integer from a linked list:

```py
integer = 0
while node:
    integer = integer * base + node.val
    node = node.next

```

**(Base can be 10 for decimal, 2 for binary, etc.)**
