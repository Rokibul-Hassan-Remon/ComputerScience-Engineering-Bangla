# ⭐ Final analogy (Real Life)

ধরো তুমি একটা স্কুলে Student register:

### ✔ Super Key

তোমাকে চিনতে পারে:

- NID
    
- Passport
    
- Phone
    
- Birth Certificate  
    সবই super key (unique করা যায়)
    

### ✔ Candidate Key

Minimal:

- NID
    
- Passport
    
- Phone  
    (সব unique identify করতে পারে)
    

### ✔ Primary Key

School choose করল:

- NID
    

### ✔ Foreign Key

তোমার ClassId যে Class টেবিলকে reference করে।

### ✔ Primary Attribute

NID → primary attribute  
যদি composite হয় (NID + SchoolCode) → দুটোই primary attribute

---

# ⭐ One-line recap:

|Term|Easy Meaning|
|---|---|
|Super Key|যেকোনো unique identifier|
|Candidate Key|Minimal unique identifier|
|Primary Key|যেটাকে main identifier বানানো হয়েছে|
|Foreign Key|অন্য টেবিলের primary key-এর reference|
|Primary Attribute|Primary key-এর ভিতরে থাকা column|
