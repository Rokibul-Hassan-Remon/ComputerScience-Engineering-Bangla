# ⭐ 2. Candidate Key

Super key গুলোর মধ্যে **যেগুলোতে extra column নেই**— অর্থাৎ smallest super key।

✔ Candidate key এক বা একাধিক হতে পারে  
✔ এগুলোর ভিতর থেকে আমরা Primary Key বাছাই করি

### Example:

Student(Id, Name, Phone)

Super keys ছিল:

- Id
    
- (Id, Name)
    
- (Id, Phone)
    
- Phone
    
- (Phone, Name)
    

Candidate keys হলো:

- **Id**
    
- **Phone**
    

কারণ এগুলো minimal এবং unique।

**Shortcut:**  
👉 _Minimal unique identifier = Candidate key_
