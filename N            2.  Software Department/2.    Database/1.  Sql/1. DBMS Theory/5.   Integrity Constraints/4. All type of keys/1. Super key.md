# ⭐ 1. Super Key

**এক বা একাধিক attribute মিলে যেটা প্রতিটা row কে unique চিনতে পারে।**

✔ Super key অনেকগুলো হতে পারে  
✔ সব super key valid key না (কিছুতে extra column থাকে)

### Example:

Relation: Student(Id, Name, Phone)

Unique identify করতে পারে:

- Id
    
- (Id, Name)
    
- (Id, Phone)
    
- (Phone)
    
- (Phone, Name)
    

এগুলো সবই **super key**।

**Shortcut মনে রাখো:**  
👉 _যে যেভাবেই unique করতে পারে — সবই super key।_
