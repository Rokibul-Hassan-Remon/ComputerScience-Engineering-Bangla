# ⭐ 3. Primary Key

Candidate keys-এর মধ্যে থেকে **database designer যে key-টিকে main identifier হিসেবে বেছে নেয়।**

✔ টেবিলের সবচেয়ে important key  
✔ Null হতে পারে না  
✔ Duplicate হতে পারে না  
✔ Relational database-এর backbone

### Example:

Candidate keys:

- Id
    
- Phone
    

Designer বেছে নিল:

- **Id**
    

So **Id হলো primary key**।

**Shortcut:**  
👉 _Chosen candidate key = Primary key_
