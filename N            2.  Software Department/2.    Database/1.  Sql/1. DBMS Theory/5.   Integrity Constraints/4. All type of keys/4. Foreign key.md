# ⭐ 4. Foreign Key

একটা টেবিলের column যা **অন্য টেবিলের primary key কে reference করে**।  
Relation তৈরি করে।

✔ এটি referential integrity maintain করে  
✔ Invalid value insert হতে দেয় না

### Example:

Students(StudentId, Name, DeptId)  
Departments(DeptId, DeptName)

এখানে:

- Students.DeptId → **Foreign key** referencing Departments.DeptId
    

**Shortcut:**  
👉 _Foreign key মানে parent table-এর primary key এর সন্তান।_
