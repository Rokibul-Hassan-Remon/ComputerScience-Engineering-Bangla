# ⭐ 5. Primary Attribute

Primary key-এর অংশ যেসব attributes আছে → **primary attributes**।

### Example:

Employee(EmpId, ProjectId, Name)

Composite primary key = (EmpId, ProjectId)

তাহলে:

- EmpId → primary attribute
    
- ProjectId → primary attribute
    
- Name → non-primary attribute
    

**Shortcut:**  
👉 _Primary key-এর column = Primary attribute_
