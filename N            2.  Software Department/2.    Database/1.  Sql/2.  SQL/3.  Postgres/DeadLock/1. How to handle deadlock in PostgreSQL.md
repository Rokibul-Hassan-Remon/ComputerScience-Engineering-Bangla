### **1️⃣ PostgreSQL MVCC (Multi-Version Concurrency Control) – Simple Bangla**

- PostgreSQL uses **MVCC** to allow multiple transactions একই সময়ে data read/write করতে।
    
- প্রতিটি row-এ থাকে **version (xmin, xmax)**: কোন transaction created বা deleted করেছে।
    
- Read queries **lock না দিয়ে** old versions access করে → high concurrency।
    
- Write query করলে নতুন row version তৈরি হয় → অন্য transaction old version পড়তে পারে।
    
- Deadlock কম হয়, কিন্তু full isolation লাগলে **still possible**।
    

> সহজভাবে: PostgreSQL MVCC “readers don’t block writers and writers don’t block readers” achieve করে।
