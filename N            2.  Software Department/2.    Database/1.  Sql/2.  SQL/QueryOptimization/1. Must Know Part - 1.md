Backend-এ Core Database knowledge আসলে কোথায় লাগে?  
  
Data Model Design করার সময়:-  
Backend API লেখার আগেই সবচেয়ে বড় সিদ্ধান্তটা হয় এখানে।  
কোনটা table হবে?  
কোনটা relation?  
Foreign key লাগবে কিনা?  
Normalize করব নাকি denormalize?  
  
ভুল data model = future scaling problem  
এটা ORM নয়, pure database thinking  
  
API Slow হলে Debug করার সময়:-  
API slow, এই কথার উত্তর code-এ সবসময় থাকে না।  
Core DB জানলে আপনি বুঝতে পারবেন  
Query কীভাবে execute হচ্ছে?  
Index ব্যবহার হচ্ছে কিনা?  
JOIN কি অপ্রয়োজনীয়  
  
এখানেই লাগে: EXPLAIN ANALYZE  
Backend developer হিসেবে এটা জানা mandatory।  
  
ORM ব্যবহার করার সময় (Django / Sequelize / TypeORM):-  
ORM আমাদের সাহায্য করে, কিন্তু অন্ধভাবে বিশ্বাস করলে বিপদ।  
Core DB knowledge থাকলে,  
N+1 query ধরতে পারবেন  
ORM generated SQL বুঝতে পারবেন  
কখন raw SQL দরকার বুঝবেন  
  
ORM =! Database understanding  
  
Large Data (100MB -1GB+) Handle করার সময়:-  
ছোট প্রজেক্টে সব ঠিকঠাক চলে।  
কিন্তু ডাটা বড় হলেই সমস্যা শুরু।  
Core DB knowledge লাগে  
Pagination vs offset  
Proper indexing  
Bulk insert/update  
Query optimization  
  
এখানেই junior আর mid/senior backend dev আলাদা হয়।  
  
Transactions & Concurrency Handle করার সময়:-  
E-commerce, payment, booking system, সব জায়গায় Double order কেন হচ্ছে?  
Stock negative যাচ্ছে কেন?  
Deadlock কেন হচ্ছে?  
  
এসবের উত্তর পাওয়া যাবে যদি জানা থাকে,  
ACID  
Isolation levels  
Row locking  
  
এগুলো framework না, database level concept।  
  
Core Database knowledge মানে বেশি SQL মুখস্থ করা না। এর মানে হলো,  
Database ভিতরে কীভাবে কাজ করে সেটা বুঝে backend decision নেওয়া। যদি আপনি backend developer হন, Core DB knowledge আপনার optional skill না, এটা career multiplier...
