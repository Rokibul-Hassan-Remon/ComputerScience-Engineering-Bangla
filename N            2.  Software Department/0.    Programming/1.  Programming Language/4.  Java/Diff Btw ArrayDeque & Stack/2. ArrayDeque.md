```java
import java.util.Stack;

public class ThreadSafeExample {
    public static void main(String[] args) throws InterruptedException {
        Stack<Integer> stack = new ArrayDeque<>();

        Runnable pushTask = () -> {
            for (int i = 0; i < 1000; i++) {
                stack.push(i);
            }
        };

        Thread t1 = new Thread(pushTask);
        Thread t2 = new Thread(pushTask);

        t1.start();
        t2.start();
        t1.join();
        t2.join();

        System.out.println("Stack size (thread-safe): " + stack.size());
    }
}

```

**❌ Output (unpredictable, vary per run):**
```txt
Stack size (not thread-safe): 1734
```
- কারণ **`ArrayDeque` synchronized নয়**, race condition এর ফলে কিছু push miss হয়েছে।
