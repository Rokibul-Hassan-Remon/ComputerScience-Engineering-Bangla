##### **KHelper - An Ultimate CP Buddy**

KHELPER কি?

জাভা/কটলিনে কম্পিটিটিভ প্রোগ্রামিং করার জন্য KHelper খুবই হেল্পফুল একটি টুল।

এটি প্রবলেম সলভিং এর সময় অনেক রিপিটিটিভ কাজ অটোমেট করে:

০১। Competitive Companion ব্রাউজার এক্সটেশনের সাথে ইন্টিগ্রেশন

০২। ফলে, ওয়ান ক্লিক স্যাম্পল ইনপুট আউটপুট পার্জিং এর সুবিধা

০৩। ইউজার ইন্টারফেসের মাধ্যমে টেস্ট কেইজ ম্যানেজমেন্ট

০৪। টেস্ট কেইজ এর জন্য সলিউশ্যান সোর্স সরাসরি রান কিংবা ডিবাগ করা যাবে

০৫। লোকাল ইম্পোর্ট ডিপেন্ডেন্সি মার্জ হয়ে সাবমিট উপযোগী ফাইল অটোজেনারেট হবে
