আসলে `costly pop` approach এর ভিতরের সেই **traverse logic** টা ধরেছো।  
চলো আমি এটাকে সুন্দর করে সাজিয়ে দিই:

---

## 🔎 কেন ১ কম traverse করতে হবে?

- আমাদের লক্ষ্য হলো stack এর **শেষ element** (যেটা latest pushed item) কে বের করা।
    
- Queue এর rule হলো FIFO, তাই সামনে থেকে একে একে remove করতে হবে।
    
- কিন্তু যদি আমরা সবগুলো element traverse করি, তাহলে শেষ element-টাও traverse হয়ে `temp queue` তে চলে যাবে।  
    👉 তখন আর আমরা শেষ element কে বের করতে পারব না — আবার একই order হয়ে যাবে (**যেই লাউ সেই কদুই**)।
    

---

### ✅ সমাধান

- তাই আমরা **১ কম traverse করবো**।
    
- মানে, `queue.size() > 1` পর্যন্ত element গুলো সরিয়ে নেব `temp queue` তে।
    
- তখন আসল **শেষ element** টা main queue তে বাকি থাকবে।
    
- আমরা সেটাকেই সরাসরি `pop()` করব।
    

---

### 🧩 সহজ উদাহরণ

Stack operations: `push(1), push(2), push(3)`

Queue এর অবস্থা: `[1, 2, 3]`  
(এখানে 1 সামনে, 3 হলো শেষ element অর্থাৎ stack এর top)

- Traverse করে `1` আর `2` `temp queue` তে নিলাম → `temp = [1, 2]`
    
- Main queue তে এখন শুধু `3` আছে → এটাই pop করব।
    

Result → Pop = `3` ✅ (stack এর সঠিক top)।

---

👉 তাই rule হলো:  
**সব element traverse করো না, শেষ element রেখে দাও → সেটাই হবে stack এর top।**



```java title:"Leetcode-225"
public class MyStack{  
    Queue<Integer> queue;  
    public MyStack() {  
        queue = new ArrayDeque<>();  
    }  
  
    public void push(int x) {  
        queue.add(x);  
		  
        for(int i = 0; i < queue.size()-1; i++){  
            int crntVal = queue.remove();  
            queue.add(crntVal);  
        }  
    }  
  
    public int pop() {  
      return queue.remove();  
    }  
  
    public int top() {  
        return queue.peek();  
    }  
  
    public boolean empty() {  
        if(queue.size() > 0)  
            return false;  
  
        return true;  
    }  
}
```
