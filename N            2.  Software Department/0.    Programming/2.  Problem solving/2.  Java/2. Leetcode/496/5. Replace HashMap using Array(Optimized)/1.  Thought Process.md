## 🧠 Amar চিন্তার ধাপ (Thinking Process)

    - প্রথমে Ami nums2 (যেটা query array) থেকে **সবচেয়ে বড় number** বের করছে → `max`.
        
    - কারণ nums2 এর বাইরে অন্য number নিয়ে মাথা ঘামাতে হবে না।

    👉 এখানে ও Hash Map ব্যবহার না করে **direct array mapping** use করছে, যাতে lookup O(1) হয়।
