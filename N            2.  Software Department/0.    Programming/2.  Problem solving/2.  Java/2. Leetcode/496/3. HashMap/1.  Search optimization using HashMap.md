### Array দিয়ে solution
1. প্রথমে `nums1[i]` কে `nums2` এর মধ্যে খুঁজে বের করতে হয়।
    
2. ওই index থেকে শুরু করে পরের element গুলো check করতে হয়।
    
3. যদি বড় element পাওয়া যায় তাহলে সেটাই answer, না পেলে `-1`।
    
4. এখানে বারবার search করতে হয় বলে কোডটা তুলনামূলকভাবে slow।

---
### Hash Map দিয়ে solution

1. আগে থেকেই `nums2` এর element গুলো Hash Map এ store করে রাখি (element → index)।
    
2. এবার `nums1[i]` এর জন্য সরাসরি map থেকে index পাওয়া যায়।
    
3. ওই index+1 থেকে শুরু করে next greater element check করা হয়।
    
4. এখানে আলাদা করে search করতে হয় না বলে কোডটা cleaner আর efficient হয়।
