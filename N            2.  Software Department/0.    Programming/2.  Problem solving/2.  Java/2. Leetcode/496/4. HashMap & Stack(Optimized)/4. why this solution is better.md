## Monotonic Stack কী?

👉 **Monotonic** মানে একরকম order এ থাকা (either increasing or decreasing)।  
👉 তাই **Monotonic Stack** মানে হলো একটা stack যেটাতে element push করার সময় এমনভাবে maintain করা হয় যাতে সব elements:

- **Monotonic Increasing Stack** → stack এ সবসময় bottom → top এর দিকে **increasing order** থাকে।
    
- **Monotonic Decreasing Stack** → stack এ সবসময় bottom → top এর দিকে **decreasing order** থাকে।
    

---

## Example দিয়ে বুঝি

ধরা যাক, 
		array = `[2, 1, 3]`

- যদি আমি **Monotonic Increasing Stack** বানাতে চাই:
    
    1. Push `2` → stack = [2]
        
    2. Push `1` → কিন্তু এখন 1 < 2, increasing rule ভেঙে যাবে, তাই আগে 2 pop করে দিতে হবে। → stack = [1]
        
    3. Push `3` → 1 < 3, ঠিক আছে → stack = [1, 3]
        

👉 Final stack = `[1, 3]` (increasing order maintained)

- যদি আমি **Monotonic Decreasing Stack** বানাই:
    
    1. Push `2` → stack = [2]
        
    2. Push `1` → 1 < 2, ঠিক আছে decreasing চলছে → stack = [2, 1]
        
    3. Push `3` → কিন্তু 3 > 1, rule ভেঙে যাবে → pop 1, pop 2, তারপর push 3  
        👉 stack = [3]
        

---

## কেন দরকার?

Monotonic Stack খুব useful **Next Greater Element**, **Next Smaller Element**, **Largest Rectangle in Histogram**, **Trapping Rain Water** এইসব problem solve করার জন্য।

কারণ এভাবে order maintain করলে **O(n²)** loop না চালিয়ে একবারের traversal এ (O(n)) next greater/smaller বের করা যায়।
