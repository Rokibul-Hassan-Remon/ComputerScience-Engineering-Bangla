এবার `nums1 = [1,2,3]`, `nums2 = [4,3,2,1]` কেসটা Step by Step দেখে নেওয়া যাক।

---

### 🛠 Algorithm recap (Monotonic Stack দিয়ে)

- একটা **stack** থাকবে যেখানে element গুলো **descending order (বড় থেকে ছোট)** এ থাকবে।
    
- যখনই কোনো নতুন সংখ্যা আসবে, stack এর top এর সাথে compare করব।
    
    - যদি top < নতুন সংখ্যা → তাহলে বোঝা যাবে top এর জন্য নতুন সংখ্যা **next greater element**।
        
    - যদি না হয় → stack এ push করব।
        
- শেষে সব mapping তৈরি হয়ে যাবে (Hash Map এর মাধ্যমে)।
    

---

### 🔎 Step-by-Step Execution

`nums2 = [4,3,2,1]`

👉 শুরুতে:

- `stack = []`
    
- `map = {}`
    

---

#### 1. num = 4

- stack ফাঁকা → শুধু push করব।
    
- stack = `[4]`
    

---

#### 2. num = 3

- `stack.peek() = 4`
    
- 4 < 3 ❌ (না) → push করব।
    
- stack = `[4,3]`
    

---

#### 3. num = 2

- `stack.peek() = 3`
    
- 3 < 2 ❌ → push করব।
    
- stack = `[4,3,2]`
    

---

#### 4. num = 1

- `stack.peek() = 2`
    
- 2 < 1 ❌ → push করব।
    
- stack = `[4,3,2,1]`
    

---

⚡ শেষ হয়ে গেল `nums2`।

- কোনো জায়গায় “peek < num” condition true হয়নি, তাই **কোনো mapping তৈরি হয়নি।**
    
- সুতরাং `map = {}`
    

---

### 🔚 Final Step (nums1 থেকে result তৈরি)

- nums1 = `[1,2,3]`
    
- map একেবারেই empty, তাই সবার জন্য `-1` return হবে।
    

👉 result = `[-1, -1, -1]`

---

### ✅ কেন এমন হলো?

কারণ `nums2 = [4,3,2,1]` হলো strictly decreasing array।

- 1 এর ডানে কিছু নেই → তাই no greater.
    
- 2 এর ডানে 1 আছে → কিন্তু সেটা ছোট।
    
- 3 এর ডানে [2,1] আছে → দুটোই ছোট।
    
- 4 এর ডানে [3,2,1] আছে → সব ছোট।
    

তাই কারও জন্য next greater element নেই।

---

📌 **Final Output:**  
`[-1, -1, -1]`
