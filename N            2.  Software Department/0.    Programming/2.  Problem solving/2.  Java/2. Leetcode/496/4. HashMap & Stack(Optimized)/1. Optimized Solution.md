
তুই যেটা লিখেছিস সেটা ঠিক আছে, কিন্তু এখনও **O(n * m)** টাইম কমপ্লেক্সিটি চলে আসছে (কারণ `nums1` এর প্রতিটা element এর জন্য আবার `nums2` এর পরে traverse করতে হচ্ছে)।

এর থেকে **ভালো solution** আছে — সেটা **Monotonic Stack + Hash Map** ব্যবহার করে।

---
### Idea:

1. `nums2` এর প্রতিটা element এর জন্য **next greater element** আগে থেকেই বের করে রাখব।
    
2. এই কাজের জন্য **Monotonic Decreasing Stack** ব্যবহার করা যায়।
    
    - Stack-এ সবসময় decreasing order এ element রাখা হবে।
        
    - যখন নতুন element আসবে যেটা stack-এর top এর চেয়ে বড়, তখন বুঝব — stack-এর top এর জন্য next greater element পাওয়া গেছে।
        
    - সেটাকে Hash Map এ রেখে দেব (key = stack-এর top, value = নতুন বড় element)।
    
3. সবশেষে `nums1` traverse করব → `Hash Map` থেকে সরাসরি answer বের করব।
