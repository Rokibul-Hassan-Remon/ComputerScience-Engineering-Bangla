## 🧠 লেখকের চিন্তার ধাপ (Thinking Process)

1. **Observation (n2 এর max বের করা)**
    
    - প্রথমে লেখক n2 (যেটা query array) থেকে **সবচেয়ে বড় number** বের করছে → `max`.
        
    - কারণ n2 এর বাইরে অন্য number নিয়ে মাথা ঘামাতে হবে না।
        
    - ও বুঝেছে: আমি একটা **array (n1)** বানাতে পারব size = max+1, যাতে number গুলোর next greater সরাসরি index দিয়ে map করে রাখা যায়।
        
    
    👉 এখানে ও` Hash Map` ব্যবহার না করে **direct array mapping** use করছে, যাতে lookup O(1) হয়।
    
1. **🚀 নিজের Stack বানানোর আইডিয়া**
	1. Stack ক্লাস (Java `Stack`) ব্যবহার করলে কিছু overhead থাকে। তাই কোডার চেয়েছে **নিজেই stack implement** করবে। Stack-এর জন্য প্রয়োজনীয় জিনিসপত্র
	
	2. **Pointer (top):**  
	    → Stack-এর শীর্ষ (top element) কোন index এ আছে সেটা ট্র্যাক করার জন্য ব্যবহার করা হয়েছে।
    
	3. **Array:**  
	    → Stack-এর ভেতরে element গুলো রাখতে একটি সাধারণ integer array ব্যবহার করা হয়েছে।
    
---

### ⚡ কেনো এটা করা হলো?

- Library `Stack` বাদ দিয়ে custom stack ব্যবহার করলে কোড কিছুটা **fast** হয়।
    
- Memory allocation আর extra method call-এর ঝামেলা কমে যায়।
    
- Direct array access (O(1)) হওয়াতে performance gain হয়।
