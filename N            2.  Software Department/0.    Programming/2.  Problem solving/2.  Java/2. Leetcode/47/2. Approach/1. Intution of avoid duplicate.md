## ২️⃣ সমস্যা কোথায় আসে?

সমস্যা আসে **যখন একই জিনিস একের বেশি থাকে**।

উদাহরণ:
```css
A, A, B

```

এখানে মোট 3টা জিনিস → আমরা প্রথমে ভাবি:
```css
3! = 6
```

কিন্তু সত্যি কি ৬টা আলাদা permutation আছে? ❌

চলো লিখে দেখি:

1. A A B
    
2. A B A
    
3. A A B ❌ (same as 1)
    
4. A B A ❌ (same as 2)
    
5. B A A
    
6. B A A ❌ (same as 5)
    

👉 আসলে unique permutation মাত্র **৩টা**।

---

## ৩️⃣ কেন duplicate হচ্ছে?

কারণ:

দুটি **A একেবারে identical**  
→ A₁ আর A₂ আলাদা না  
→ ওদের জায়গা বদলালেও **নতুন permutation তৈরি হয় না**

মানে:
```css
A₁ A₂ B  ==  A₂ A₁ B
```
কিন্তু `3!` গণনায় আমরা এগুলোকে আলাদা ধরে ফেলেছি 😵

---

## ৪️⃣ তাই আমরা ভাগ করি কেন?

আমরা যা ভুল করেছি:

- A গুলোর নিজেদের মধ্যে permutation গুনে ফেলেছি
    

দুটি A আছে → ওদের নিজেদের permutation:
```css
2! = 2
```
এই 2টা permutation **আসলে একই জিনিস**

👉 তাই extra count ঠিক করতে আমরা ভাগ করি:
```css
Actual unique permutation
= 3! / 2!
= 6 / 2
= 3
```

## ৫️⃣ General rule (মুখস্থ করার লাইন)

যদি কোনো জিনিস:

- x বার repeat হয়
    
- y বার repeat হয়
    
- z বার repeat হয়
    

তাহলে:
```css
n! / (x! × y! × z!)

```
