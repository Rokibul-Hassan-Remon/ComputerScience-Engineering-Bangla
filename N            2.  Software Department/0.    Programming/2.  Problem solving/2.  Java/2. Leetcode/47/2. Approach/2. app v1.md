**Unique permutation বের করার একটাই সঠিক mindset আছে:**

> ❌ duplicate permutation বানিয়ে পরে filter করবো না Which will be so costly
> ✅ duplicate permutation **বানাতেই দেবো না** It will be more efficient.

এই goal মাথায় রাখলেই সব clear।

## ✅ Step-by-step Procedure (যেটা follow করলে success)

### ✅ STEP 1: Array অবশ্যই sort করো
```java
Arrays.sort(nums);
```

**কেন?**  
Duplicate গুলো পাশাপাশিই থাকুক → তখন আমরা control করতে পারবো।

---

### ✅ STEP 2: permutation তৈরি করো “position by position”

প্রতিবার:

- path এ **একটা সংখ্যা বসাও**
    
- depth = path.size()
    

---

### ✅ STEP 3: isVisited[ ] ব্যবহার করো
```java 
boolean[] isVisited = new boolean[nums.length];
```

এর মানে:

- এই index টা আগেই path এ ব্যবহার করা হয়েছে কিনা
    
---

### ✅ STEP 4: for loop সব element এর উপর
```java
for (int i = 0; i < nums.length; i++)
```

Permutation মানে:

> প্রতিটা position এ সব candidate চেষ্টা করতে হবে

---

### ✅ STEP 5 (🔥 সবচেয়ে গুরুত্বপূর্ণ): duplicate skip rule
```java
if (i > 0 && nums[i] == nums[i - 1] && !isVisited[i - 1])
    continue;

```

#### এই rule কী enforce করে?

> “একই value থাকলে **আগেরটাকে না নিয়ে পরেরটা নেবে না**”

মানে:

- duplicate number গুলোকে **left-to-right order** এ ব্যবহার করতেই হবে
    
- উল্টো করে ব্যবহার করা নিষিদ্ধ
    

👉 এখানেই combinatorics এর `/ x!` logic code এ translate হয়

### 🔹 Problem Context

আমাদের কাজ হলো **array থেকে সব unique permutation বের করা**।  
কিন্তু যখন array-তে **duplicate element** থাকে (যেমন `1,1,2`), তখন একই permutation একাধিকবার generate হওয়ার সম্ভাবনা থাকে।

## 🔹 Why Sorting is Necessary
```java
	int[] nums = {1, 2, 1};
```

প্রথমে array-টি sort করলে পাই:

```java
	int[] nums = {1, 1, 2};

```

👉 Sorting করার ফলে **সব duplicate element একসাথে চলে আসে**,  
যার কারণে আমরা খুব সহজেই **duplicate branch detect ও skip** করতে পারি।

---

## 🔹 Duplicate কেন হয়? (Intuition)

ধরো আমরা root level-এ:

- index 0 থেকে `1` নিলাম
    
- আবার index 1 থেকে `1` নিলাম
    

তাহলে তৈরি হয়:
```java 
	1, 1
```

এবার উল্টো করে ভাবো:

- আগে index 1 এর `1`
    
- পরে index 0 এর `1`
    

তাতেও তৈরি হয়:
```java
	1, 1
```

👉 এই দুইটার মধ্যে **কোনো পার্থক্য নেই**।  
এই কারণেই combinatorics-এ আমরা বলি:
```java
	Total permutations / (duplicate item)!
```

কিন্তু program-এ আমরা **শেষে ভাগ না দিয়ে**,  
👉 **আগেই duplicate branch তৈরি হওয়া বন্ধ করে দিই**।
