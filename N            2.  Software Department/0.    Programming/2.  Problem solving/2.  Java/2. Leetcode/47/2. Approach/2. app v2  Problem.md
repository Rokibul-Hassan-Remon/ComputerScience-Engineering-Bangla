# 🧠 LeetCode 47 — Permutation II

## Swap-based Recursion Tree & Duplicate Pruning (Revision Note)

---

## ⚠️ Important Mental Model

এখানে দেখানো recursion tree টি **swap-based permutation tree**।  
এটি **path-based backtracking নয়**।

এখানে প্রতিটি recursion level-এ `crntIndx` position fix করা হয়  
এবং array mutate (swap) হয়।

## 🔍 Observation (What to Notice)

এখানে দেখার বিষয় এই যে, যাদের পাশে cross দেওয়া এগুলো র উপর আর রিকার্সন method কল করা যাবে না।  
তাহলে আমাদের আর **duplicacy arise** হবে না।  
তাহলে আমরা সকল unique permutation পাবো।

এই cross গুলো same recursion level-এ  
একই value আবার `crntIndx` এ বসানোর attempt বোঝায়।

---

## 🧠 Core Rule (Invariant)

**At each recursion level,  
the same value should not be placed at `crntIndx` more than once.**

অর্থাৎ, একই level-এ duplicate value দিয়ে  
একাধিক branch তৈরি করা যাবে না।

এই rule ভাঙলেই duplicate permutation তৈরি হয়।  
তাই যেসব branch-এ একই value আবার `crntIndx` এ বসানো হচ্ছে,  
সেগুলো prune (❌) করা হয়।

## ❓ Decision Point

### Cross (❌) দেওয়া recursion গুলো কিভাবে identify করবো?

তাহলে প্রশ্ন আসে যে কিভাবে আমরা এই cross চিহ্ন যুক্ত recursion method গুলোকে identify করবো।

---

## 🧩 Key Insight

১) duplicate element গুলো নিজেদের মধ্যে swap করালে তা নতুন কোনো permutation generate করে না।  
আর তাই একটা উপায় হলো duplicate element গুলোকে track রাখা।

তাই swap-based approach-এ duplicate remove করতে হলে  
comparison করতে হবে **recursion level অনুযায়ী**,  
array state অনুযায়ী নয়।

## ❌ Wrong Approach (Why It Fails)

```java title:"Leetcode-47: Permutation II"
public static  List<List<Integer>> permuteUnique(int[] nums) {  
    List<List<Integer>> res = new ArrayList<>();  
    List<Integer> path = new ArrayList<>();  
  
    backtrack(nums, 0, res);  
  
    return res;  
}  
  
public static void swap(int[] arr, int i, int j){  
    int temp = arr[i];  
    arr[i] = arr[j];  
    arr[j] = temp;  
}  
  
public static void backtrack(int[] nums, int crntIndx, List<List<Integer>> res){  
    if(crntIndx == nums.length ){  
        ArrayList<Integer> base = new ArrayList<>();  
  
        for(int each: nums){  
            base.add(each);  
        }  
  
        res.add(base);  
  
        return;  
    }  
  
    for(int i = crntIndx; i < nums.length; i++){  
          
        if(i != crntIndx && nums[i] == nums[crntIndx]) continue;  
  
        swap(nums, crntIndx, i);  
  
        backtrack(nums, crntIndx+1, res);  
  
        swap(nums, crntIndx, i);  
    }  
}
```

### এই condition টা কী ধরে নিচ্ছে?

👉 “current index-এর value এর সাথে যদি same হয়, skip করবো”

কিন্তু সমস্যা হলো:

- `nums[crntIndx]` **swap এর কারণে বদলে যায়**
    
- তাই তুমি **original state জানো না**
    

ফলে:

- কিছু duplicate skip হয় না ❌
    
- কিছু valid permutation ভুল করে skip হয় ❌
    

---

## 💥 Counter Example (Where It Breaks)

ধরি:

`nums = [1, 1, 2]`

### crntIndx = 0

- i = 0 → swap(0,0) → [1,1,2]
    
- i = 1 → nums[1] == nums[0] → skip ✅
    
- i = 2 → swap(0,2) → [2,1,1]
    

এখন crntIndx = 1 এ গেলে:

`nums = [2,1,1]`

এখানে:

- i = 1
    
- i = 2 → nums[2] == nums[1]
    

👉 কিন্তু এই `nums[1]` আগের swap-এর ফল  
👉 এটা original comparison না

ফলে logic unreliable হয়ে যায়।

---

## ✅ Final Takeaway (Confirmation)

- Swap-based tree-তে array mutate হয়
    
- তাই `nums[crntIndx]` reliable reference না
    
- Duplicate remove করতে হলে  
    **same recursion level-এ value reuse prevent করতে হবে**
