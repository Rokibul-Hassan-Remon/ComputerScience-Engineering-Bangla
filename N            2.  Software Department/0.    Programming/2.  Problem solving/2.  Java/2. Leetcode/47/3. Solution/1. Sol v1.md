
## 🔹 Core Duplicate-Skip Condition

```java
if (i > 0 && nums[i] == nums[i - 1] && !isVisited[i - 1])
     continue;
```

### 🔍 Meaning

> **আগের duplicate element যদি এই branch-এ না নেওয়া হয়,  
> তাহলে পরের duplicate element নেওয়া যাবে না।**



```java title:"Leetcode-47:  Permutation II"
	public static List<List<Integer>> permuteUnique(int[] nums) {  
	    Arrays.sort(nums);  
	  
	    List<List<Integer>> res = new ArrayList<>();  
	    boolean[] isVisited = new boolean[nums.length];  
	    List<Integer> path = new ArrayList<>();  
	  
	    backtrack(nums, isVisited, res, path);  
	  
	    return res;  
	}  
	  
	public static void backtrack(int[] nums, boolean[] isVisited, List<List<Integer>> res, List<Integer> path){  
	    if(path.size() == nums.length ){  
	        res.add(new ArrayList<>(path));  
	  
	        return;  
	    }  
	  
	    for(int i = 0; i < nums.length; i++){  
	        if(isVisited[i] == true) continue;  
	  
	        if(i > 0 && nums[i] == nums[i - 1] && isVisited[i-1] == false) continue;  
	  
	        isVisited[i] = true;  
	        path.add(nums[i]);  
	  
	        backtrack(nums, isVisited, res, path);  
	  
	        path.removeLast();  
	        isVisited[i] =false;  
	    }  
	}
```
