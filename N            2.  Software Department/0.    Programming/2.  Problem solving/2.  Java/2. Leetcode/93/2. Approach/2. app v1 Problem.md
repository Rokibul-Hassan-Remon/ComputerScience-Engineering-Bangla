## 🔴 বড় সমস্যা ২: Backtracking structure ভুল

IP restore problem এ আসল decision হয়:

- প্রতি segment 1 digit নেবো?
    
- না 2 digit?
    
- না 3 digit?
    

অর্থাৎ branching factor = 3

কিন্তু তোমার recursion:

```txt
segment - 1 করে কমাচ্ছে
কিন্তু segment size vary করছে না
```

মানে:

ami প্রতি recursive call এ শুধু 1 character নিচ্ছো।

কিন্তু IP segment 3 digit পর্যন্ত হতে পারে।

এখানেই approach conceptually ভেঙে গেছে।

# 🎯 আসল সমস্যা কোথায়?

```txt
At position start:     
	Try:         
		1 digit segment         
		2 digit segment         
		3 digit segment     
	If valid → recurse`
```

amr approach:

```txt
Last character থেকে
```
