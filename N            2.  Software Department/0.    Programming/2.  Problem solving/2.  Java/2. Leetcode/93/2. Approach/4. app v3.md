# Valid IP Address (32 bit)

একটি valid IPv4 address:

- মোট 32 bit
    
- ৪টি segment
    
- প্রতিটি segment → 0 থেকে 255
    
- প্রতিটি segment → 1–3 digit
    

---

# 💡 Idea: Given String কে ৪ খন্ডে ভাগ করা

তুমি বলছো:

> যদি given string কে একসাথে ৪ খন্ড করে ফেলি?

হ্যাঁ — এটাই আসল চিন্তা।

কারণ IP সবসময় ৪টা অংশেই ভাগ হবে।

তাই problem টা আসলে দাঁড়ায়:

👉 string এ কোথায় ৩টা dot বসাবো?

---

# 🎯 3 Pointer Approach কেন কাজ করে?

যেহেতু ৪টা segment লাগবে,  
তাই ৩টা cut point লাগবে।

ধরি string = `"25525511135"`

আমরা ৩টা pointer নেবো:

```java
	i  → প্রথম কাট
	j  → দ্বিতীয় কাট 
	k  → তৃতীয় কাট
```

তাহলে segment গুলো হবে:

```java
s[0, i) s[i, j) s[j, k) s[k, n)
```

---

# 📌 Loop Structure (Conceptual)

```java
for i = 1 to 3
   for j = i+1 to i+3  
      for k = j+1 to j+3
```

কারণ:

- প্রতিটি segment সর্বোচ্চ 3 digit
    
- সর্বনিম্ন 1 digit
    

---

# 🔍 এরপর কী check করবো?

প্রতিটি segment এর জন্য:

### ✅ 1️⃣ Length ≤ 3

### ✅ 2️⃣ No leading zero (except single "0")

### ✅ 3️⃣ Value ≤ 255

যদি ৪টিই valid হয় → add to result

---

# 🧠 কেন এই approach clean?

এই problem এ:

- recursion প্রয়োজন নেই
    
- stack প্রয়োজন নেই
    
- reverse traversal প্রয়োজন নেই
    

কারণ:

👉 maximum length = 12  
👉 fixed 4 segment  
👉 brute force possibilities খুব কম

Worst case:

```java
3 × 3 × 3 = 27 possible splits
```

এটা খুবই ছোট।
