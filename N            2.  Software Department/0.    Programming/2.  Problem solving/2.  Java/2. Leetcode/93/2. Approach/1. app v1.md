## 📌 ১️⃣ IP Address Structure

32 বিট বিশিষ্ট IP address মূলত ৪ ভাগে বিভক্ত।  
আর প্রতি ভাগে থাকে সর্বোচ্চ ৩ টি করে ডিজিট অথবা সর্বনিম্ন ১ করে ডিজিট।

তাহলে একটি সম্পূর্ণ ভেলিড IP address এ থাকে সর্বোচ্চ ১২ টি অথবা সর্বনিম্ন ৪ টি ডিজিট।

👉 তারমানে যদি ৪ এর কম অথবা ১২ টির বেশি character থাকলে return null list।

---

## 📌 ২️⃣ Problem Statement থেকে গুরুত্বপূর্ণ শর্ত

### 🔹 (a) Leading Zero Rule

Problem statement এ বলা ছিলো যে,

```txt
11.02.33.123
```

এরকম হলে তা Invalid IP address।

কেনো?  
কারণ, কোনো valid IP address এ কোনো segment এর শুরুতে শূন্য (0) থাকে না।

---

### 🔹 (b) Digit Validation Rule

আবার, `0 - 9` ব্যাতীত অন্য কোনো char থাকতে পারবে না।

👉 তারমানে, আমাদের এই জিনিসটা চেক করে নিতে হবে valid IP হিসাবে add করার জন্য।

---

## 📌 ৩️⃣ Recursion Strategy (Reverse Traversal Idea)

যেহেতু valid IP list return করতে হবে তাহলে,

যদি আমরা always given string এর শেষের দিক থেকে traverse করি তাহলে আমরা recursion এর  
base case condition এ `indx == 0` এটা সেট করতে পারবো।

### ✅ এতে সুবিধা হলো:

- আমাদের string এর length জানার জন্য সব সময় `s.length()` call করতে হবে না।
    
- ফলে, আমাদের API call বেচে যাবে।
    
- control আমার হাতেই থাকছে।
    

---

## 📌 ৪️⃣ Stack Based Construction Logic

আর যেহেতু আমরা শেষের দিক থেকে traverse করবো তাই আমাদের stack নিতে হবে।

তাহলে যেটা হবে:

- আমরা পেছন থেকে traverse করে আসবো
    
- এবং তা stack এ রাখবো
    

ফলে যখন base case এ পৌঁছাবে তখন আমরা stack থেকে pop করে নিয়ে string form করবো।

তখন valid IP এর শুরুর দিকের character stack এর একদম top এ থাকবে।

এইভাবে আমরা char pop করে string form করে এটাকে string এর list এ add করে দিবো।
