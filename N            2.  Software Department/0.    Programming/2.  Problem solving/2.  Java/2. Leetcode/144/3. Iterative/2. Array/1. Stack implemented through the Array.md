```java title:"Leetcode-144"
public class solution{
	//Leetcode predefined method
	public List<Integer> preorderTraversal(TreeNode root) {

        List<Integer> list = new ArrayList<>();
        TreeNode[] Nodes = new TreeNode[100];
        int top = -1;
        
        if(root == null) return list;
        
        Nodes[++top] = root;
        while(top!=-1){
        
            TreeNode temp = Nodes[top--];
            list.add(temp.val);
            
            if(temp.right != null) Nodes[++top] = temp.right;
            if(temp.left != null) Nodes[++top] = temp.left;
        }
        
     return list;
    }
}

```

যেহেতু array দিয়ে stack বানাচ্ছো, 

>TreeNode[ ] stack = new TreeNode[100];  

→ যদি tree-তে 100 এর বেশি node থাকে, তাহলে আবারও সমস্যা হবে (`ArrayIndexOutOfBoundsException`)।

তাই real safe version করতে চাইলে **dynamic stack** (যেমন `java.util.Stack` বা `ArrayDeque`) ব্যবহার করাই ভালো ।

নিশ্চয়! আমি তোমার জন্য **iterative preorder traversal** এর দুইটি approach-এর **Time & Memory comparison table** বানিয়ে দিচ্ছি।

|Approach|Time Complexity|Space Complexity|Observed Run Time|Observed Memory Usage|
|---|---|---|---|---|
|**Array-based Stack**|O(n)|O(n) (fixed array, may waste space)|0.058 s|9.18 MB|
|**Dynamic Stack (List / ArrayDeque)**|O(n)|O(n) (only needed space)|0.064 s|1.55 MB|
