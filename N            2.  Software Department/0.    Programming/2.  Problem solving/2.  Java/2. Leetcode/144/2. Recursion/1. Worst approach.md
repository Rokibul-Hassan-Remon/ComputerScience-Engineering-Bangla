```java title:"Leetcode-144"
class Solution {
    public static List<Integer> PreOrderTraversal(TreeNode root){
        if(root == null )
        {
            List<Integer> baseResult = new ArrayList<>();
            
            return baseResult;
        }
    
        List<Integer> list = new ArrayList<>();
        List<Integer> list3 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();

        list.add(root.val);

        if(root.left != null)
            list3 = PreOrderTraversal(root.left);
        if(root.right != null)
            list2 = PreOrderTraversal(root.right);
        for(var child : list3){
            list.add(child);
        }
        for(var child : list2){
            list.add(child);
        }

        return list;
    }

    public List<Integer> preorderTraversal(TreeNode root){
        return PreOrderTraversal(root);
    }
}
```

```txt
This approach uses too much memory because I declared and used three separate lists. That is why it is a poor approach.
```
