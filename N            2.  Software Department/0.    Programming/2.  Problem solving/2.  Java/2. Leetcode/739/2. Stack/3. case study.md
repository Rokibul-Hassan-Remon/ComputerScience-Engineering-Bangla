## 🔹 Case 1: Strictly Increasing Prices

`prices = [1, 2, 3, 4, 5]`

- i=0 → stack empty, push(0)
    
- i=1 → prices[0]=1 >= 2 ❌ → push(1)
    
- i=2 → prices[1]=2 >= 3 ❌ → push(2)
    
- i=3 → prices[2]=3 >= 4 ❌ → push(3)
    
- i=4 → prices[3]=4 >= 5 ❌ → push(4)
    

শেষে stack = [0,1,2,3,4], while loop শেষে সব result = original prices।

👉 এখানে while loop **কখনোই execute হয় না**।  
তাহলে মোট কাজ: শুধু push (n বার) + শেষে pop (n বার) → **O(n)**।

---

## 🔹 Case 2: Strictly Decreasing Prices

`prices = [5, 4, 3, 2, 1]`

- i=0 → push(0)
    
- i=1 → prices[0]=5 >=4 ✅ → pop(0), result[0]=5-4=1, push(1)
    
- i=2 → prices[1]=4 >=3 ✅ → pop(1), result[1]=4-3=1, push(2)
    
- i=3 → prices[2]=3 >=2 ✅ → pop(2), result[2]=3-2=1, push(3)
    
- i=4 → prices[3]=2 >=1 ✅ → pop(3), result[3]=2-1=1, push(4)
    

শেষে stack=[4], তাই result[4]=1।

👉 এখানে প্রতিটা element **push একবার, pop একবার**।  
তাহলে মোট কাজ: n push + n pop → **O(n)**।

## 🔹 General Case

যত mix হোক না কেন (increasing + decreasing),

- প্রতিটা index সর্বোচ্চ একবার push হবে,
    
- প্রতিটা index সর্বোচ্চ একবার pop হবে।
    

তাহলে while loop-এর ভিতরের operations মোটে **O(n)** বার হবে, O(n² না।
