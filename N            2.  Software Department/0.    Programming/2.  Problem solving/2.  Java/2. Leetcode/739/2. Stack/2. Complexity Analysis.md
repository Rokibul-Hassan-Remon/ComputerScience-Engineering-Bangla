### 🔹 কেন তোমার মনে হচ্ছে O(n²)?

কারণ তোমার loop এর ভিতরে একটা `while` loop আছে → দেখে মনে হতে পারে nested loop, মানে n × n = n²।

কিন্তু আসলে এটা misleading।

---

### 🔹 আসল ব্যাপার
```java 
while (!stack.isEmpty() && prices[stack.peek()] >= prices[i]) {
    int idx = stack.pop();
    result[idx] = prices[idx] - prices[i];
}

```
এখানে প্রতিটা element **stack-এ push হয় মাত্র একবার** এবং **stack থেকে pop হয় মাত্র একবার**।  
তাহলে মোট কতবার while loop চলবে?  
👉 Maximum n বার (কারণ প্রতিটা element একবারই pop হতে পারবে)।

---

### 🔹 Total Operations

- `for` loop → n বার চলে।
    
- প্রতিটা element push → n বার।
    
- প্রতিটা element pop → n বার।
    

তাহলে মোট operation ~ `2n` এর মতো।  
মানে **O(n)**।

---

### 🔹 তুলনা

- তোমার version → O(n)
    
- আমার version → O(n)
    

Space Complexity দুজনেরই O(n) (stack + result array)।

---

✅ Verdict:  
**দুটোই linear time solution।**  
তোমার code O(n² না, বরং O(n))।
