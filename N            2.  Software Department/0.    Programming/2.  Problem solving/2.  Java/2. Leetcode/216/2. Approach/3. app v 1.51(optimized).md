# 📘 LeetCode 216 – Combination Sum III (Optimized with Path-Based Pruning)
---

## 🔍 Core Idea

- User input `k` **পরিবর্তন করা ঠিক নয়**।
    
- আগের version-এ আমরা প্রতি recursion level-এ `k` কমাচ্ছিলাম, কিন্তু এটা **user input পরিবর্তন** করা।
    
- এখন **path.size()** ব্যবহার করে pruning করা হবে।
    
- অর্থাৎ, loop এর upper bound প্রতি recursion level-এ হবে:
    

`i <= 9 - (k - path.size()) + 1`

- Base case এ **check** করতে হবে:
    

`k == path.size()`

## 🔁 Backtracking Pruning

1. **Path-based count pruning**:
    

```java
for (int i = start; i <= 9 - (k - path.size()) + 1; i++)
```

- কারণ: path.size() already taken numbers = `len(path)`
    
- Remaining numbers needed = `k - path.size()`
    
- Ensure enough numbers left
---

## ⚠ Base Case
```java 
if (crntSum == n || k == path.size()) {
    if (crntSum == n && k == path.size()) {
        res.add(new ArrayList<>(path));
    }
    return;
}

```

- k সংখ্যক number নেওয়া **এবং** sum ঠিক হলে → valid combination
    
- অন্য যেকোনো case → return
