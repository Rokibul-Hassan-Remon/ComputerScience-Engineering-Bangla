# 📘 LeetCode 216 – Combination Sum III 
---

### Take a look : 

**Example 3:**

**Input:** 
```io
k = 4, n = 1
```

**Output:** 
```io
[]
```

**Explanation:** There are no valid combinations.
Using 4 different numbers in the range `[1,9]`, the smallest sum we can get is 1+2+3+4 = 10 and since 10 > 1, there are no valid combination.

**Constraints:**

- `2 <= k <= 9`
- `1 <= n <= 60`

# 🎯 Core Insight

যদি এমন input দেওয়া হয় যা আদৌ mathematically possible না,  
তাহলে অযথা recursion call করে time এবং memory waste করার কোনো প্রয়োজন নেই।

তাই backtracking শুরু করার আগে  
**minimum এবং maximum possible sum check করা উচিত।**

---

# 🔢 Minimum & Maximum Range Check

## 🔹 Minimum Possible Sum

১–৯ এর মধ্যে সবচেয়ে ছোট `k`টি সংখ্যা নিতে হবে।

$$minSum=1+2+3+...+k$$

Example:
```css
k = 4
minSum = 1+2+3+4 = 10
```

---

## 🔹 Maximum Possible Sum

১–৯ এর মধ্যে সবচেয়ে বড় `k`টি সংখ্যা নিতে হবে।

$$maxSum=9+8+7+...+(9−k+1)$$

Example:
```css
k = 4
maxSum = 9+8+7+6 = 30

```

---

## 🚨 Feasibility Rule
```css
if (n < minSum || n > maxSum)
    return empty list

```

---

# 🔁 Loop Range Control (Count-Based Pruning)

আমাদের `k` সংখ্যক সংখ্যা নিতে হবে।

তাই loop এমন জায়গা পর্যন্ত চলবে  
যেখানে থেকে এখনও `k`টি সংখ্যা নেওয়া সম্ভব।

Maximum starting point:

$$9−k+1$$

So loop হবে:

```java
for (int i = start; i <= 9 - k + 1; i++)

```

এবং প্রতি recursion level-এ:
```java
k → k - 1

```
কারণ আমরা একটি সংখ্যা already নিয়েছি।

---

# ⚠ Important Edge Cases During Recursion

## 1️⃣ k সংখ্যক সংখ্যা নিয়েছি কিন্তু sum ≠ n

→ invalid  
→ return

---

## 2️⃣ sum == n কিন্তু k সংখ্যক সংখ্যা হয়নি

→ invalid  
→ return

---

## 3️⃣ k == 0 এবং sum == n

→ valid combination  
→ result.add()

---

# ➕ Sum-Based Pruning

যদি দেখি:

`currentSum + selectedNumber > n`

তাহলে:

`break / return`

কারণ সংখ্যা সব positive এবং increasing।

এর পরের সংখ্যা আরও বড় হবে,  
তাই আর explore করার দরকার নেই।

---

# 🧠 Full Logical Structure

Backtracking-এর ভিতরে মূল decision flow:
```sql

1️⃣ যদি k == 0:
       যদি sum == n → add
       return

2️⃣ for i from start to 9 - k + 1:
       যদি currentSum + i > n → break
       choose i
       recurse with k-1
       unchoose i

```
