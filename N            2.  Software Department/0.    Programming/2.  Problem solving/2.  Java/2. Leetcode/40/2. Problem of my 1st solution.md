
## 🔴 1️⃣ সবচেয়ে বড় সমস্যা: LC-40 এ `Collections.sort(path)` ❌

এই লাইনটা:

`Collections.sort(path);`

❌ **ভুল জায়গায় ভুল কাজ**

### কেন?

- LC-40 এ **combination-এর order matter করে না**
    
- কিন্তু recursion-এর সময় `path` sort করলে:
    
    - recursion tree ভেঙে যায়
        
    - same combination multiple way তৈরি হয়
        
- এটা **duplicate generate করার root cause**
    

👉 **Rule:**

> Backtracking-এর মাঝখানে কখনো `path` modify করে sort করা যাবে না

`Collections.sort(res);`
