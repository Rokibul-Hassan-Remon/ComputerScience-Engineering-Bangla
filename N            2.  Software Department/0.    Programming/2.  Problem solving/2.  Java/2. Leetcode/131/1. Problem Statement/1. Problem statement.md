Given a string `s`, partition `s` such that every substring of the partition is a **palindrome**. Return _all possible palindrome partitioning of_ `s`.

**Example 1:**

**Input:** 
```io
s = "aab"
```
**Output:** 
```io
[["a","a","b"],["aa","b"]]
```

**Example 2:**

**Input:**
```io
 s = "a"
```
**Output:** 
```io
[["a"]]
```

**Constraints:**

- `1 <= s.length <= 16`
- `s` contains only lowercase English letters.
