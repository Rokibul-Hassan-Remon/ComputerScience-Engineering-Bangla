Dockerfile কী?  
  
Dockerfile হলো একটি plain-text স্ক্রিপ্ট যেখানে Docker image তৈরি করার জন্য প্রয়োজনীয় সব instructions থাকে। প্রতিটি instruction ইমেজে একটি করে layer তৈরি করে। এর ফলে version control করা সহজ হয় এবং build process হয় fast, efficient and reproducible  
  
Key Concepts  
  
Image  
একটি read-only টেমপ্লেট, যেখান থেকে Docker container তৈরি হয়। এর ভেতরে থাকে অ্যাপের কোড, runtime, লাইব্রেরি ও প্রয়োজনীয় সেটিংস।  
  
Container  
Docker image থেকে চালু হওয়া একটি runnable instance। এটি একটি isolated environment যেখানে অ্যাপ রান করে।  
  
Syntax  
1. Instruction সাধারণত convention অনুযায়ী UPPERCASE এ লেখা হয়  
2. লাইন ধরে execute হয়  
3. # দিয়ে comment লেখা হয়  
4. ফাইলের নাম হতে হবে Docker file (কোনো extension ছাড়া)  
  
Dockerfile-এর সাধারণ Instruction  
  
FROM  
base image নির্ধারণ করে। সবসময় প্রথম instruction হতে হয়।  
  
RUN  
Build চলাকালীন নতুন একটি layer এ কমান্ড run করে (যেমন package install করা)।  
  
WORKDIR  
কন্টেইনারের working directory সেট করে।  
  
COPY  
Host machine থেকে ফাইল/ফোল্ডার কন্টেইনারে কপি করে।  
  
ADD  
COPY এর মতোই, তবে remote URL নিতে পারে এবং compressed ফাইল auto extract করতে পারে।  
  
ENV  
Environment variable সেট করে (build ও runtime দুটোতেই কাজ করে)।  
  
EXPOSE  
কন্টেইনার কোন port-এ listen করবে তা জানায় (documentation হিসেবে)।  
নোট: বাস্তবে port publish করতে docker run -p ব্যবহার করতে হয়।  
  
CMD  
কন্টেইনার রান হলে default কোন কমান্ড চলবে তা নির্ধারণ করে। override করা যায়।  
  
ENTRYPOINT  
কন্টেইনারকে executable-এর মতো ব্যবহার করতে দেয়।
