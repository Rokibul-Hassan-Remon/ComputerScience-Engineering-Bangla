# 🔰 Hypervisor Types & Bare Metal – Complete Note

## 1️⃣ Bare Metal কী?

**Bare Metal** মানে একদম খাঁটি, raw(`naked`) physical hardware—  
যেখানে প্রথমে কোনও OS বা software layer থাকে না।

উদাহরণ:  
CPU, RAM, Storage, Motherboard—সব hardware ready, `কিন্তু OS নেই`।

👉 Bare Metal = “ন্যাড়া hardware” (কোনও OS/Hypervisor ছাড়া)

---

## 2️⃣ Hypervisor কী করে?

Hypervisor একটি special software layer যা Bare Metal hardware বা OS-এর উপরে বসে  
multiple Virtual Machine (VM) তৈরি ও manage করে।

Hypervisor resource (CPU/RAM/Disk) ভাগ করে বহু OS একসঙ্গে চালাতে দেয়।

---

## 3️⃣ Hypervisor-এর দুইটি মূল Type

---

### 🔷 **Type-1 Hypervisor (Bare-Metal Hypervisor)**

Hypervisor **সরাসরি Bare Metal hardware**-এর উপর install হয়।  
এখানে কোনও OS-এর প্রয়োজন নেই।

📌 Key Features

- Highest performance
    
- Very low latency
    
- Highly secure
    
- Cloud/data center-এ ব্যবহৃত হয়
    

📌 Examples

- **VMware ESXi**
    
- **Microsoft Hyper-V (bare-metal mode)**
    
- **Xen**
    
- **KVM (Linux kernel acts as hypervisor)**
    

📌 Real-world analogy  
খালি জমির উপর সরাসরি boundary বানিয়ে তার ভিতরে বাড়ি (VM) বানানো।

👉 **Type-1 Hypervisor = Bare Metal Hypervisor**

---
### 🔶 **Type-2 Hypervisor (Hosted Hypervisor)**

এটি **existing OS-এর উপর** install হয়।  
Flow: `Hardware → OS → Hypervisor → VM`

📌 **Key Features**

- Desktop users/dev environment
    
- Easy to install
    
- Slower than Type-1
    

📌 Examples

- **VirtualBox**
    
- **VMware Workstation**
    
- **Parallels Desktop**
    

📌 Real-world analogy  
আগে apartment building (OS) বানানো হয়, তারপর সেই building-এর ভিতরে রুম (VM) বানানো হয়।

---

## 4️⃣ Hypervisor Concepts (Good to know)

### 🟣 Paravirtualization

- Guest OS জানে সে VM-এর ভিতরে চলছে
    
- Better performance  
    (Used by Xen)
    

### 🟡 Hardware-Assisted Virtualization

- CPU features (Intel VT-x, AMD-V) Hypervisor-কে faster করে
    
- Type-1 ও Type-2 দুটোতেই ব্যবহার হয়
    

---

## 5️⃣ Final Summary (One Look)

|Concept|Meaning|
|---|---|
|**Bare Metal**|Raw physical hardware (no OS)|
|**Type-1 Hypervisor**|Direct Bare Metal-এ install হয়, fastest, secure|
|**Type-2 Hypervisor**|OS-এর উপর install হয়, slower but easy|
|**VM**|Virtual computer created by Hypervisor|

👉 তাই Hypervisor এবং Bare Metal-এর সম্পর্ক:  
**Bare Metal hardware → Type-1 Hypervisor → Multiple VM**  
অথবা  
**Bare Metal hardware → OS → Type-2 Hypervisor → VM**
